# Подбор организационно-правовой формы

Учебная лабораторная по экономике предприятия, 3 курс. Приложение помогает обосновать выбор формы организации по цели, ресурсам, составу участников и способу управления.

## Запуск

В Git Bash из папки проекта:

```bash
node server.js
```

Из любой папки:

```bash
/c/nodejs/node.exe 'C:/Users/MAX/Desktop/BusinessForm/server.js'
```

Откройте http://127.0.0.1:8765. Остановка — Ctrl+C. После обновления файлов перезапустите сервер. Node.js уже установлен на ноутбуке. Платные сервисы и установка пакетов не нужны.

## Пользовательский путь

1. Выберите цель проекта простыми словами.
2. Ответьте на относящиеся к ней вопросы. Скрытые вопросы не участвуют в обработке.
3. Получите рекомендацию, причины и ограничения. Подробные баллы раскрываются отдельно.
4. Для коммерческого сценария посмотрите условный финансовый пример по деятельности, масштабу и управлению.

## Алгоритмы

### Обычный бизнес

Сначала проверяются ограничения: совместное владение, акции, личная ответственность и уставный капитал. Затем оставшиеся формы получают знаковые баллы.

Вклад критерия = вес × (2 × коэффициент соответствия − 1). Коэффициент меняется от 0 до 1, поэтому вклад может быть отрицательным, нулевым или положительным.

Веса: собственность и инвестиции 25, управление 20, корпоративный учёт 15, деятельность 15, масштаб 15, риск 10. Суммарный балл лежит от −100 до +100. Это экспертные учебные веса, а не статистическая оценка вероятности успеха. При равенстве используется порядок ИП, ООО, АО.

### Сельское хозяйство и совместный труд

К обычным формам добавляются КФХ или производственный кооператив. Проверяются участие, ответственность и состав. Кооператив получает преимущество при личном труде и голосовании по одному голосу участника.

### Общественная деятельность и общие потребности

Формы сравниваются по цели, членству и финансированию. В общественной ветке рассматриваются АНО, фонд, ассоциация, общественная организация, движение и учреждение. Для общих потребностей — потребительский кооператив и ТСН.

### Особый статус

Для 13 направлений подготовлены отдельные профили условий: полное товарищество, товарищество на вере, хозяйственное партнёрство, личный фонд, местная религиозная организация, унитарное предприятие, публично-правовая компания, госкорпорация, адвокатская палата, коллегия адвокатов, нотариальная палата, казачье общество и община коренных малочисленных народов.

Пользователь отвечает «да», «нет» или «пока не знаю». Отрицательный ответ на базовое условие означает препятствие, неизвестный — необходимость уточнения. Даже все положительные ответы дают только предварительный результат. Документы и дополнительные специальные условия приложение не проверяет.

Результат содержит разбор каждого условия, экономические особенности, следующие шаги и ссылку на норму. Для отдельных форм область проверки явно сужена: личный фонд при жизни учредителя, местная религиозная организация, коллегия адвокатов.

## Финансовый пример

Из ответов автоматически выбираются условные цена, объём и затраты. Для сравниваемых форм используется одна выручка. Разницу формируют затраты на учёт, управление и условные взносы.

Выручка = цена × продажи.
Общие расходы = расходы на единицу × продажи + постоянные расходы.
Результат = выручка − общие расходы − учёт и управление − условные взносы − условный налог.

Налог 6% от выручки используется как единое допущение. Применимость режимов, НДС, льготы и уменьшение налога на взносы не моделируются. Финансовая таблица охватывает только ИП/ООО/АО. Для специальных и некоммерческих форм она скрыта, экономические особенности описаны словами. Пример объясняет механику расчёта и не является прогнозом конкретного бизнеса.

## Структура

- server.js — HTTP-сервер, привязанный к 127.0.0.1, с фиксированным списком разрешённых файлов.
- public/index.html — актуальная разметка приложения.
- public/styles.css — стили.
- public/app.mjs — поведение интерфейса и показ результатов.
- public/selection.mjs — подбор и баллы.
- public/special.mjs — условия, вопросы и источники специальных форм.
- public/economics.mjs — формулы и типовые финансовые допущения.
- tests/check.cjs — проверки условий, веток, финансового примера и переходов интерфейса.

## Проверка

```bash
node tests/check.cjs
```

Проверяются положительные, отрицательные и неопределённые ответы по каждому специальному условию, подача всех специальных анкет, переход обратно к бизнесу, основные цели и финансовый контрольный пример. Тесты интерфейса используют модель DOM. Это не визуальная проверка страницы в браузере.

## Правовая база

Проверка условий специальных форм проведена 24.11.2026. Ссылки на конкретные статьи открываются в результатах соответствующей анкеты.

Основные акты: ГК РФ, № 14-ФЗ, № 208-ФЗ, № 380-ФЗ, № 161-ФЗ, № 7-ФЗ, № 125-ФЗ, № 63-ФЗ, № 154-ФЗ, № 104-ФЗ, № 236-ФЗ от 03.07.2016 и Основы законодательства о нотариате.

Это каталог основных категорий и учебная проверка базовых условий, а не полный классификатор всех подтипов ОКОПФ. Применяются специальные ограничения и отраслевые нормы.

## Безопасность

Работа в браузере на ноутбуке, без передачи ответов на внешние сервисы и сохранения анкеты. Сервер не предоставляет запись файлов, выполнение команд или просмотр каталогов. Ссылки на правовые источники загружаются только при их открытии пользователем.


## Проверка обычных веток от 24.11.2026

Для ИП/ООО/АО, КФХ, производственного кооператива и шести некоммерческих направлений добавлены экономические пояснения, следующие шаги и источники. Правила НКО учитывают минимальное число учредителей ассоциации и общественного объединения, единственного собственника учреждения, отсутствие распределения прибыли и соответствие цели. Для ТСН проверяется наличие недвижимости у участников. При конфликте цель не подменяется неподходящей формой с низким баллом.

Назначение формы проверяется в пределах выбранной модели: например, для представления интересов рассматривается членская ассоциация. Для альтернативной структуры нужно пересмотреть цель и членство. Специальные подтипы кооперативов и их количественные требования уточняются отдельно.

Финансовый пример может дать более высокий результат у формы, которая не лидирует по предпочтениям. Это объясняется рядом с таблицей: условные издержки не заменяют оценку управления, собственности и риска.

Проверки: 115 условий особого статуса, 13 путей подачи специальных анкет, шесть основных целей, 256 сочетаний ответов НКО, 14 карточек пояснений и семь запросов к работающему HTTP-серверу. В браузере проверены бизнес, НКО, конфликт целей, кооператив, КФХ, общая недвижимость и специальный статус, а также отсутствие ошибок JavaScript в этих сценариях. Это проверенные контрольные сценарии, а не гарантия покрытия каждого возможного сочетания.

Актуальные исходники интерфейса находятся в public/. Если в корне остался index.html от первой версии, сервер его не использует.
