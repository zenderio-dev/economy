# Выбор формы бизнеса

Учебное веб-приложение по экономике предприятия. Помогает выбрать организационно-правовую форму по условиям проекта и объясняет рекомендацию.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Откройте [приложение](http://127.0.0.1:8765/). Команда `npm run build` собирает файлы в `dist/`, а `npm run preview` запускает локальный просмотр сборки.

## Публикация на GitHub Pages

Workflow `Deploy to GitHub Pages` проверяет и собирает приложение для пути `/economy/` при пуше в `main`. Для первой публикации выберите **GitHub Actions** в [Settings → Pages](https://github.com/zenderio-dev/economy/settings/pages) и запустите workflow из вкладки [Actions](https://github.com/zenderio-dev/economy/actions/workflows/pages.yml).

## Как пользоваться

1. Выберите цель проекта. Для обычной коммерческой деятельности подходит «Продавать товары или оказывать услуги».
2. Ответьте на вопросы анкеты и нажмите «Получить рекомендацию».
3. Прочитайте описание подходящей формы и следующие шаги. В разделе сравнения можно увидеть оценки и ограничения остальных форм.
4. Для допустимых коммерческих форм из группы ИП, ООО и АО доступен условный расчёт за месяц. Ставка 6% от выручки и суммы расходов заданы как учебные допущения.

Приложение также рассматривает сельское хозяйство, совместный труд, общественные задачи, общие потребности и формы с особым статусом. При несовместимых ответах оно показывает ограничения. Ответы обрабатываются в браузере и сбрасываются при перезагрузке страницы.

## Почему выбраны эти критерии

| Критерий | Как влияет на выбор |
| --- | --- |
| Вид деятельности | Помогает учесть особенности торговли, услуг и производства и выбрать финансовый пример. |
| Масштаб | Влияет на оценку сложности управления проектом и на объём продаж в модели. |
| Число учредителей | Определяет, нужна ли форма с юридически оформленным совместным владением, и позволяет проверить ограничения по составу. |
| Инвестиции | Различает собственное финансирование, оформление доли и привлечение денег через акции. |
| Ответственность | Учитывает готовность участников отвечать по долгам личным имуществом. |

В коммерческих ветках дополнительно учитываются капитал, управление, вид корпоративного учёта и планы роста. Алгоритм применяет ограничения, затем ранжирует допустимые формы по экспертным весам. Источники и допущения описаны в [экономической части](docs/ECONOMICS.md). Состав модулей описан в [технической части](docs/TECHNICAL.md).
